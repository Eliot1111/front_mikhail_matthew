# Тише

Простой сайт для сосредоточенной работы на чистых HTML, CSS и JavaScript.

## Запуск

Откройте `index.html` двойным щелчком в браузере. Устанавливать модули, запускать сервер или подключаться к интернету не нужно. Держите `index.html`, `style.css` и `script.js` в одной папке.

## Возможности

- Таймер: 25 минут работы или 5 минут перерыва.
- Запуск, пауза, продолжение и сброс таймера.
- Добавление, отметка выполнения и удаление задач.
- Сохранение задач в localStorage браузера.
- Адаптивный интерфейс для телефона и компьютера.

Таймер сбрасывается при обновлении страницы. Задачи сохраняются, если браузер разрешает локальное хранилище; они доступны в том же браузере и по тому же пути к файлу. При недоступном хранилище сайт продолжит работать и покажет подсказку.

## Файлы

- `index.html` — разметка.
- `style.css` — оформление, цвета и адаптивность.
- `script.js` — таймер и работа с задачами. Длительности задаются в объекте `durations` в начале файла.
